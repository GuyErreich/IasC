# Personal-IaC

This repository serves as a centralized collection of Infrastructure as Code (IaC) configurations and automation scripts. It is designed to provide modular, scalable, and reusable solutions for managing cloud infrastructure, while offering the flexibility to grow with new use cases.

## Highlights

- **Structured Organization:** Each IaC solution resides in its own dedicated folder for clarity and ease of navigation.
- **Diverse Solutions:** Includes setups for AWS ECS Fargate deployments, CI/CD pipeline configurations, GitHub self-hosted runners, and more.
- **Custom Automation:** Features scripts for efficient scaling, resource monitoring, and cost optimization.
- **Secure Practices:** Utilizes AWS Secrets Manager for secure and reliable secrets management.
- **Future-Ready Design:** The repository framework is adaptable for incorporating new IaC configurations to meet evolving requirements.

## Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/GuyErreich/Personal-IaC.git
   ```

2. **Explore available solutions**:
   Navigate to the desired folder based on your use case. Each folder includes its own `README.md` with detailed setup and deployment instructions. Key examples include:
   - [**GitHub Self-Hosted Runner for Unreal Engine**](GitHub%20Self-Hosted%20Runner%20For%20UnrealEngine/): Configurations for GitHub self-hosted runners, currently tailored for Unreal Engine 5 (UE5). Future expansions may include broader support.
   - 

3. **Follow folder-specific instructions**:
   Open the `README.md` in your chosen folder and complete the steps to deploy or manage your desired solution.

## Adding New IaC Configurations

This repository is structured for growth. To contribute a new IaC configuration:
- **Create a new folder or branch:** Use a descriptive name that reflects the solution's purpose.
- **Document thoroughly:** Add a `README.md` in folders or detailed notes in the branch to explain setup, deployment, and key details for users.
- **Ensure compatibility:** Maintain consistency with existing practices for seamless integration.
